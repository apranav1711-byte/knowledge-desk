# Sample files

Fictional policies for demos. Sign in as an admin or manager and upload them from **Documents**.

| File | Classify as | Try asking |
| --- | --- | --- |
| `supplier-travel-policy.pdf` | General Internal | What is the hotel limit for a domestic trip? |
| `management-approval-matrix.pdf` | Management | When is director approval required for a purchase? |
| `travel-and-expense-policy.md` | General Internal | Can I claim a taxi from the airport? |
| `onboarding-equipment.txt` | General Internal | What equipment does a new employee receive? |

`backend/demo/` holds more (leave, remote work, compensation bands → HR Confidential, department budget and expansion strategy → Management).
Demo: ask the Management file's question as an Employee user — it must return the "not enough evidence" answer, never the content.
